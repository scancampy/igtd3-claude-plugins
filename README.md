# IGTD Claude Plugins

Marketplace plugin untuk mata kuliah **Intelligent Game Technology & Design** (Magister Informatika). Saat ini berisi satu plugin: **IGTD Assessment 3 Kit**, pendamping mahasiswa untuk Assessment 3 (Build an Intelligent Game Feature).

## Cara memasang (sekali saja)

Plugin memerlukan akun Claude paket berbayar (Pro, Max, Team, atau Enterprise).

1. Buka claude.ai, lalu pilih **Customize > Plugins**.
2. Pilih **Add > Add marketplace**, lalu masukkan alamat repository ini (format `username/nama-repository` atau URL GitHub-nya).
3. Pasang plugin **IGTD Assessment 3 Kit** dari marketplace tersebut.
4. Buka percakapan baru dan tanyakan: "Skill apa saja yang kamu miliki dari plugin?" Pastikan plugin muncul.

Jika ada kendala pemasangan, hubungi dosen pengampu.
